These six files form one evidence chain for a small data-science project.

| Artifact | Blank template | Completed example |
| --- | --- | --- |
| Decision brief | [research-brief.md](research-brief.md) | [example](../examples/deliverables/research-brief.md) |
| Data profile | [data-profile.md](data-profile.md) | [example](../examples/deliverables/data-profile.md) |
| Prepared-data code | [prepared-data.py](prepared-data.py) | [example](../examples/deliverables/prepared-data.py) |
| Model comparison | [model-comparison.csv](model-comparison.csv) | [example](../examples/deliverables/model-comparison.csv) |
| Evaluation memo | [evaluation.md](evaluation.md) | [example](../examples/deliverables/evaluation.md) |
| Decision memo | [memo.md](memo.md) | [example](../examples/deliverables/memo.md) |

The completed examples use the customer-churn case and its committed results.
They are intentionally short; the goal is a clear evidence trail, not document
length.
