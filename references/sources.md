# Sources and further reading

This tutorial is an original synthesis. It does not reproduce the wording or
code of the sources below.

## Process model

- Wirth, R., & Hipp, J. (2000). *CRISP-DM: Towards a Standard Process Model for Data Mining.* Proceedings of the 4th International Conference on the Practical Application of Knowledge Discovery and Data Mining.
- IBM. *What is CRISP-DM?* https://www.ibm.com/think/topics/crisp-dm

## Python and machine-learning implementation

- pandas documentation: https://pandas.pydata.org/docs/
- scikit-learn User Guide: https://scikit-learn.org/stable/user_guide.html
- scikit-learn `Pipeline` and `ColumnTransformer`: https://scikit-learn.org/stable/modules/compose.html
- scikit-learn model evaluation: https://scikit-learn.org/stable/modules/model_evaluation.html
- Matplotlib documentation: https://matplotlib.org/stable/

## Data note

All three tutorial datasets are generated by `src/tutorial/data.py` using fixed
random seeds. They contain no confidential, personal, or employer data.
